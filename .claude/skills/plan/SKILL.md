# Plan a Qaida Change

Before editing, read `AGENTS.md` and `docs/memory/README.md`. Produce a compact plan with:

1. Scope and non-goals.
2. Exact files to create or modify.
3. Lesson-data, asset-path, responsive, and accessibility risks.
4. Acceptance criteria.
5. The narrowest verification command, plus `npm.cmd run build` when application behavior changes.

Record durable decisions in `docs/memory/decision-log.md` and update `docs/memory/development-status.md` after verification.
